# 3분 시연영상 대본

- 목표 길이: **2분 55초** (3분을 넘기면 심사에서 잘린다)
- 화면: 터미널 16pt 이상, 브라우저 확대 125%, 창은 1280×800 고정
- 원칙: **한 장면에 한 주장.** 말로 설명하지 않고 화면으로 증명한다.

## 촬영 전 준비 (당일 즉흥 금지)

유실 장면은 재현이 까다로워 즉석에서 만들면 실패한다. 아래 한 줄이 커밋됨·미커밋·
이후 변경됨·**유실**·판정 불가가 모두 있는 저장소와 세션 기록을 통째로 만들어 준다.

```bash
node tools/demo.mjs --dir C:/ccaudit-demo     # macOS·Linux 는 ~/ccaudit-demo
cd C:/ccaudit-demo/할일앱
git log --oneline                              # 커밋 3개가 보이면 준비 완료
```

촬영용 두 번째 터미널은 이 폴더에서 열어 둔다. 리포트는 미리 한 번 생성해
브라우저 캐시를 데워 두되, **녹화 시작 전에 탭을 닫는다**.

| 준비물 | 확인 |
|---|---|
| 데모 저장소 (`tools/demo.mjs`) | 5개 파일이 각각 다른 git 상태 |
| 터미널 2개 | ① 저장소 폴더 ② 리포트 생성용 |
| `.env` 파일 | 마스킹 장면용 — 화면에 열지 않는다 |
| 네트워크 | `npx openccaudit` 첫 실행이 느릴 수 있어 사전 워밍업 |

## 0:00 ~ 0:30 — 문제 제기

> "Claude Code로 2주를 작업했습니다. 그래서, 무슨 파일이 어떻게 바뀌었죠?"

화면:

```bash
git status          # 깨끗하다. 아무 일도 없었던 것처럼 보인다
git log --oneline   # 커밋 3개. 그 사이에 무슨 일이 있었는지는 안 나온다
```

내레이션 요지:
- 커밋 사이에 Claude가 만든 파일, 고쳤다가 되돌린 파일, **커밋 없이 사라진 변경**은
  git이 알려주지 않는다.
- `/rewind`는 **지금 이 세션 안에서만** 동작한다. 세션이 끝나면 그 이력은 사라진다.

## 0:30 ~ 0:50 — 실행

> "설치할 것 없습니다. 한 줄이면 됩니다."

```bash
npx openccaudit --open
```

화면에 그대로 나오는 두 줄을 잠깐 보여준다.

```
ccaudit: ccaudit-report.html
  세션 2 · 생성 4 · 수정 1 · 미커밋 1 · 유실 1 · 마스킹 4
```

강조: **의존성 설치 없음, 로그인 없음, 네트워크로 아무것도 보내지 않음.**

## 0:50 ~ 1:40 — 파일 감사

브라우저가 뜬 상태에서:

1. 상단 요약 줄 — 세션·생성·수정·미커밋·유실 (2초)
2. 파일 목록 — `src/할일.ts`, `notes/설계.md` 처럼 **한글 파일명이 그대로** 보인다
3. `README.md` 를 펼친다 → **원본 → 현재 diff**. 커밋되지 않은 변경까지 나온다
4. 배지를 짚는다: `커밋됨` / `미커밋` / `이후 변경됨` / `판정 불가`
5. `세션` 탭으로 이동 → 그 변경을 만든 **대화**가 그대로 있다

한 문장으로: **"파일에서 대화로, 대화에서 파일로 왕복할 수 있습니다."**

## 1:40 ~ 2:20 — 유실 발견 (가장 강한 장면)

`notes/설계.md` 를 짚는다. 배지는 **`유실`**.

> "Claude가 이 파일에 쓴 마지막 내용이 지금 디스크에도, git 히스토리에도 없습니다."

화면으로 증명한다:

```bash
git log --oneline -- notes/설계.md   # 커밋 자체가 없다
cat notes/설계.md                     # 지금 내용은 Claude가 쓴 것과 다르다
```

리포트의 `경고` 탭 → `lost-change` 한 줄.

> "git status는 조용합니다. 이걸 알려주는 건 지금 이 리포트뿐입니다."

## 2:20 ~ 2:45 — 한글 경로

터미널에서 세션 폴더를 그대로 보여준다.

```bash
ls ~/.claude/projects/
# C--Users-me-work---------      ← 공모전\임베디드 와 공모전\오픈소스 가
# C--Users-me-work---------      ← 같은 이름으로 뭉개져 충돌한다
```

> "Claude Code는 폴더 이름을 만들 때 한글을 대시 하나로 바꿉니다. 서로 다른 프로젝트가
> 같은 폴더에 섞입니다. ccaudit은 이 이름을 아예 믿지 않고, **세션 기록 안의 cwd로
> 프로젝트를 다시 조립합니다.**"

리포트 상단의 프로젝트 경로가 한글 그대로인 것을 보여주고, 다른 프로젝트 파일이
섞이지 않았음을 파일 목록으로 확인시킨다.

## 2:45 ~ 3:00 — 마무리

- **파일 하나.** 서버도 계정도 없이 팀에 그대로 공유하거나 CI 아티팩트로 남긴다.
- **시크릿 마스킹이 기본.** 상단 "시크릿 4건이 마스킹되었습니다" 배너를 짚는다.
- **MIT · npm 공개 · Windows/macOS/Linux × Node 18·20 CI 그린.**

마지막 화면: `npx openccaudit --open` 한 줄과 저장소 주소.
